# 小说创作大师 - AI 智能写作软件

一个功能强大的 AI 驱动小说创作平台，支持章节大纲生成、内容创作、角色管理和世界设定。

## 功能特点

### 1. 项目管理
- 创建和管理多个小说项目
- 每个项目独立配置（作者角色、创作规则、目标字数、发布平台）
- 支持番茄、七猫、知乎等多平台格式

### 2. 章节大纲生成
- 输入故事创意，AI 自动生成章节大纲
- 支持逐章生成，确保内容质量
- 可编辑、保存、删除章节大纲

### 3. 小说内容生成
- 基于章节大纲生成完整小说内容
- 使用角色状态保持人物一致
- 引用世界设定确保世界观连贯
- 读取前面章节保持情节连续
- 自动扩写达到目标字数
- 智能状态更新建议

### 4. 设定管理
- 角色状态管理（主角、配角、反派）
- 世界设定管理（世界观、力量体系、地理环境等）
- AI 智能分析建议

### 5. 生成进度监控
- 实时查看创作日志
- 章节字数统计
- 生成进度显示
- 错误提示信息

### 6. DeepSeek 浏览器集成
- 内嵌浏览器登录 DeepSeek
- 实时查看 AI 对话过程
- 透明遮罩防止误操作
- 捕获进度记录

## 技术栈

- **前端框架**: Vue 3 + Vite
- **UI 组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **桌面应用**: Electron

## 安装和运行

### 1. 安装依赖

```bash
npm install
```

### 2. 开发模式运行

```bash
npm run electron:dev
```

这将同时启动 Vite 开发服务器和 Electron 应用。

### 3. 构建生产版本

```bash
npm run electron:build
```

构建完成后，安装包将位于 `dist-electron` 目录。

## 使用指南

### 第一步：登录 DeepSeek

1. 点击左侧菜单「捕获进度」
2. 点击「打开 DeepSeek」按钮
3. 在浏览器中使用微信扫码或账号登录

### 第二步：创建项目

1. 进入「项目管理」页面
2. 点击「新建项目」
3. 填写项目信息：
   - 项目名称
   - 项目描述
   - 作者角色（定义 AI 的身份）
   - 创作规则（设定写作风格）
   - 目标字数（每章字数）
   - 发布平台（番茄/七猫/知乎）

### 第三步：生成章节大纲

1. 进入「章节大纲」页面
2. 输入故事创意和主题
3. 选择章节数量和风格类型
4. 点击「生成大纲」
5. 在右侧编辑和保存章节

### 第四步：添加角色和设定

1. 进入「设定管理」页面
2. 添加主要角色，设定角色状态和简介
3. 添加世界设定，如世界观、力量体系等

### 第五步：生成小说内容

1. 进入「小说生成」页面
2. 选择要生成的章节
3. 配置生成选项：
   - 使用角色状态
   - 引用世界设定
   - 关联前面章节
   - 自动扩写
4. 点击「复制提示词」
5. 将提示词粘贴到 DeepSeek 并发送
6. 将 AI 返回的内容复制回应用并保存

### 第六步：查看进度

1. 进入「生成进度」页面
2. 查看项目统计、生成进度和操作日志
3. 查看章节详情列表

## 开发说明

### 数据存储

项目数据存储在用户数据目录中：
- Windows: `%APPDATA%/novel-creator-pro/`
- macOS: `~/Library/Application Support/novel-creator-pro/`
- Linux: `~/.config/novel-creator-pro/`

### 提示词模板

应用会根据配置自动生成提示词，包含：
- 作者角色设定
- 章节信息和大纲
- 角色状态（如果启用）
- 世界设定（如果启用）
- 前情提要（如果启用）
- 创作规则
- 目标字数
- 平台风格
