📦 安装指南

系统要求

  • 操作系统: Windows 10 或更高版本
  • 内存: 建议 4GB 以上
  • 磁盘空间: 至少 500MB 可用空间

🌐 快速开始 - 浏览器版本（推荐）

无需安装任何软件，直接双击 browser-version.html 即可使用！

第一步：安装 Node.js（仅 Electron 版本需要）

  1. 访问 Node.js 官网：https://nodejs.org/
  2. 下载 LTS (长期支持) 版本（推荐）
  3. 运行安装程序，按默认设置完成安装
  4. 验证安装：打开命令提示符，输入 node -v，显示版本号即为成功

第二步：安装项目依赖

  1. 打开项目文件夹：c:\Users\Administrator\Desktop\客户
  2. 在文件夹中按住 Shift 键，右键点击空白处
  3. 选择「在此处打开 PowerShell 窗口」
  4. 输入以下命令并回车：
npm install

💡 等待安装完成（可能需要几分钟）

第三步：运行软件

开发模式运行（推荐用于测试）

npm run electron:dev

构建生产版本（打包成 .exe 安装包）

npm run electron:build

构建完成后，安装包位于 dist-electron 文件夹中。

📋 完整工作流程示例

1 登录 DeepSeek

  • 启动软件后，点击左侧菜单「捕获进度」
  • 点击「打开 DeepSeek」按钮
  • 在弹出的浏览器中使用微信扫码或账号登录
  • 登录成功后保持浏览器打开

2 创建你的第一个小说项目

  • 点击左侧菜单「项目管理」
  • 点击「新建项目」按钮
  • 填写项目信息：
    • 项目名称: 例如「我的玄幻小说」
    • 项目描述: 简单描述故事背景
    • 作者角色: 你是一位资深的网络小说作家，擅长创作引人入胜的玄幻故事，文笔流畅，情节紧凑。
    • 创作规则: 
      1. 语言口语化，符合网络小说风格
2. 每章设置悬念，吸引读者继续阅读
3. 人物形象鲜明，性格突出
4. 节奏适中，张弛有度
    • 目标字数: 2000（每章字数）
    • 发布平台: 番茄小说
  • 点击「创建」

3 添加主要角色

  • 点击左侧菜单「设定管理」
  • 点击「添加角色」
  • 填写角色信息：
    • 角色名称: 主角名
    • 角色定位: 主角
    • 当前状态: 初入秘境，修为低微
    • 角色简介: 详细描述性格、外貌、背景故事
  • 点击「保存」
  • 重复添加其他重要角色

4 设定世界观

  • 在「设定管理」页面，点击「添加设定」
  • 填写设定信息：
    • 设定名称: 修炼体系
    • 设定分类: 力量体系
    • 设定内容: 详细描述境界划分、修炼方法等
  • 点击「保存」
  • 继续添加地理环境、势力组织等设定

5 生成章节大纲

  • 点击左侧菜单「章节大纲」
  • 填写信息：
    • 故事创意: 详细描述你的故事创意、主题、核心情节
    • 章节数量: 10（或根据需要调整）
    • 风格类型: 玄幻
  • 点击「生成大纲」
  • 在右侧编辑和调整每章的标题和大纲
  • 点击「保存全部」

6 生成小说内容

  • 点击左侧菜单「小说生成」
  • 从左侧选择要生成的章节（从第1章开始）
  • 确认生成选项已勾选：
    • ✅ 使用角色状态
    • ✅ 引用世界设定
    • ✅ 关联前面章节
    • ✅ 自动扩写
  • 点击「复制提示词」
  • 切换到 DeepSeek 浏览器
  • 将提示词粘贴到对话框并发送
  • 等待 AI 生成内容
  • 将 AI 返回的内容复制
  • 回到「小说生成」页面，粘贴到「正文内容」框
  • 点击「保存」
  • 查看智能状态更新建议，点击「应用」更新设定
  • 重复此步骤生成后续章节

7 查看进度

  • 点击左侧菜单「生成进度」
  • 查看项目统计、生成进度和操作日志
  • 查看所有章节的详细信息

💡 功能详解

1. 项目管理

创建项目

  • 项目名称: 给小说起个名字
  • 项目描述: 简要介绍故事
  • 作者角色: 定义 AI 的写作身份，例如：
    你是一位资深的网络小说作家，拥有十年写作经验，擅长玄幻、都市题材，文笔流畅，情节紧凑，人物塑造鲜明。
  • 创作规则: 设定写作风格和要求，例如：
    1. 语言要口语化，避免晦涩难懂 2. 每章结尾必须设置悬念 3. 对话要符合人物性格 4. 打斗场景要精彩描写 5. 注重情感描写和人物成长
  • 目标字数: 建议 1500-3000 字/章
  • 发布平台:
    • 番茄小说: 节奏快，悬念强，短句多
    • 七猫小说: 类似番茄，可稍长
    • 知乎: 文风可以更细腻
    • 通用: 平衡风格
⚠️ 点击「删除」会删除整个项目，此操作不可恢复！

2. 章节大纲生成

生成大纲

  • 故事创意: 尽可能详细地描述，包括：
    • 故事主题
    • 主角设定
    • 核心冲突
    • 预期结局
  • 章节数量: 建议首次 10-20 章
  • 风格类型: 玄幻、都市、仙侠、言情、悬疑、科幻等
💡 建议详细填写大纲，这直接影响正文质量。大纲应包含：情节发展、人物出场、关键事件、章节悬念

3. 小说内容生成

生成选项说明

选项 作用 建议
使用角色状态 AI 会参考当前角色状态来写作 ✅ 始终开启
引用世界设定 AI 会遵守已设定的世界观 ✅ 始终开启
关联前面章节 AI 会参考前面章节保持连贯 ✅ 第2章及以后开启
自动扩写 AI 会详细描写达到目标字数 ✅ 开启

目标字数

  • 番茄/七猫: 1500-2500 字
  • 知乎/其他: 2000-4000 字
✨ 生成内容后，AI 会建议更新角色状态和世界设定，点击「应用」可自动更新！

4. 设定管理

角色管理

  • 角色定位:
    • 主角: 核心人物，详细描述
    • 配角: 重要配角，也需详细
    • 反派: 对手角色
    • 其他: 路人角色
  • 当前状态: 随时更新，AI 会参考
  • 角色简介: 建议包含：外貌描写、性格特点、背景故事、能力/修为

世界设定管理

  • 设定分类:
    • 世界观: 时代背景、社会结构
    • 力量体系: 修炼等级、能力系统
    • 地理环境: 地图、地点介绍
    • 势力组织: 门派、家族、国家
    • 其他: 其他重要设定

5. 生成进度监控

  • 项目统计: 总章节数、已完成数、总字数、平均章节字数
  • 操作日志: 记录所有重要操作，可清空日志
  • 章节详情: 查看所有章节的状态和字数

❓ 常见问题

Q: npm install 失败怎么办？

A:

  1. 检查网络连接
  2. 尝试使用淘宝镜像：
    npm config set registry https://registry.npmmirror.com npm install

Q: 软件打不开？

A:

  1. 确认 Node.js 已正确安装
  2. 删除 node_modules 文件夹，重新 npm install
  3. 检查是否有杀毒软件拦截

Q: 如何备份项目数据？

A:

浏览器版本: 点击右上角「导出数据」按钮

Electron 版本: 项目数据存储在：

  • Windows: C:\Users\你的用户名\AppData\Roaming\novel-creator-pro\

定期备份该文件夹即可

Q: AI 生成的内容不满意怎么办？

A:

  1. 更详细地填写章节大纲
  2. 完善角色和世界设定
  3. 调整创作规则
  4. 手动编辑生成的内容

Q: 可以同时打开多个项目吗？

A: 可以创建多个项目，但同一时间只能选择一个项目进行操作。

Q: 支持导出小说吗？

A: 当前版本可手动复制内容，后续版本会添加一键导出功能（支持 TXT、EPUB 等格式）。

✍️ 写作技巧

提高生成质量的建议

1. 详细的大纲

  • 每章大纲至少 100 字
  • 包含情节的起承转合
  • 明确章节目标

2. 丰富的设定

  • 主要角色要有详细简介
  • 力量体系要清晰
  • 地理环境要具体

3. 明确的规则

  • 在「创作规则」中详细说明
  • 可以指定文风
  • 可以禁止某些内容

4. 逐章生成

  • 不要一次性生成太多
  • 每章完成后检查
  • 根据需要调整后续大纲

5. 手动润色

  • AI 生成后建议手动修改
  • 调整不符合预期的部分
  • 保持个人风格

🛟 技术支持

如有问题，请检查：

  1. Node.js 版本是否为最新 LTS
  2. 依赖是否完整安装
  3. 项目文件夹路径是否正确
